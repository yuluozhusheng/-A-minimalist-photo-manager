# 照片管家 PhotoManager

一个 Windows 桌面工具，用于导入照片和视频、按日期归档、查找内容完全相同的重复文件。

在同一个窗口里完成整理和去重：先查看结果，再决定如何处理。

## 主要功能

- **按内容去重**：先按大小分组，再计算 SHA-256；文件名不同也能识别相同内容。
- **合并导入**：目标扫描范围内已有相同内容时跳过，避免重复导入。
- **同名冲突单独存放**：同名但内容不同的文件放入 `_同名冲突`；冲突目录内再次重名时追加编号，保留已有文件。
- **复制或移动**：复制模式保留源文件；移动模式在执行前要求确认。
- **按日期归档**：可按年或“年 / 年-月”生成文件夹。
- **筛选文件类型**：全部文件、仅照片、仅视频，可选择是否包含子文件夹。
- **试运行**：预演导入计划，不复制、移动源文件，也不创建目标文件或目录。程序本身仍会记录日志和设置。
- **可视化去重列表**：查看每组文件的名称、大小和位置，调整勾选后再删除；每组至少保留一份。
- **删除请求发送到回收站**：通过 Windows 回收站接口处理；恢复能力取决于所在磁盘和系统设置。

程序在本机处理文件，无需账号，也不上传照片。

## 下载与运行

1. 打开本仓库的 **Releases** 页面，下载 `PhotoManager.exe`。
2. 放到你有写入权限的文件夹，双击运行。
3. 运行环境为 **Windows 10 / 11 + .NET Framework 4.8 或更高版本**。程序使用 Windows Forms，不支持 macOS 和 Linux。

下载页的 `Source code` 是源码；直接使用程序请选择 `PhotoManager.exe`。

## 导入照片和视频

1. 在“① 导入（并集）”页选择源文件夹、目标文件夹。
2. 选择文件类型，以及是否包含子文件夹。
3. 首次使用可选择“复制”，勾选“试运行”，查看日志中的导入计划。
4. 确认目标路径和归档方式后，取消“试运行”，开始正式导入。
5. 如开启导入后自动扫描，正式导入完成后会跳转到去重页；扫描本身不会删除文件。

不按日期归档时，可保留源文件夹结构，或将文件平铺到目标目录。启用日期归档后，以日期目录为准。

| 归档选项 | 输出示例 |
| --- | --- |
| 不归档 + 保持目录结构 | `目标目录/原子目录/IMG.jpg` |
| 年 / 年-月 | `目标目录/2024/2024-01/IMG.jpg` |
| 年 | `目标目录/2024/IMG.jpg` |

判重范围受“包含子文件夹”影响。需要合并整个照片库时，请勾选该选项。目标已有相同内容时，即使选择移动模式，也会跳过源文件并保留源文件。

## 单独查找重复文件

1. 切换到“② 去重”，选择需要扫描的目录和文件类型。
2. 开始扫描，查看重复组。默认建议保留的那份不勾选，其余重复文件预勾选。
3. 逐组检查；双击列表行可在资源管理器中定位文件。
4. 点击“删除选中的重复（到回收站）”，确认后执行。

默认保留顺序为：没有 `_数字` 后缀的文件优先，其次目录层级较浅、创建时间较早，最后按路径排序。可以手动调整勾选；如果整组全被勾选，程序会自动保留一份。

## 日期识别方式

依次尝试以下来源：

1. 图片 EXIF：原始拍摄时间、数字化时间、图片时间。
2. 对视频尝试读取 MP4/MOV 结构中的 `mvhd` 创建时间。
3. 文件名：如 `IMG_20240102_030405`、`20240102`、`wx_camera_时间戳`、`mmexport_时间戳`。
4. 文件修改时间；读取失败时使用当前时间。

日期读取取决于文件内容和系统解码支持。能按扩展名识别、复制某种格式，不代表一定能读取它的拍摄时间。视频容器时间也可能是导出时间；导入前请用试运行检查。

## 支持的类型

- 照片：JPG、PNG、GIF、BMP、TIFF、WebP、HEIC、HEIF、AVIF、JXL，以及 ARW、CR2、CR3、NEF、DNG 等相机原始格式。
- 视频：MP4、MOV、AVI、MKV、WMV、3GP、TS、MTS、WebM 等。
- 选择“全部文件”时，也可以整理其他类型的文件。

完整的扩展名列表见 `Program.cs` 中的 `ImageExt` 和 `VideoExt`。

## 从源码构建

本项目是一个 C# 源文件，使用 .NET Framework 自带编译器，不依赖 NuGet 包。

1. 将仓库下载并解压到本机。
2. 双击 `build.bat`，或在命令提示符中运行：

```bat
build.bat
```

成功后生成 `dist/PhotoManager.exe`。如提示找不到编译器，请检查 .NET Framework 4.8 的安装情况。

## 日志与设置

- 运行日志为程序目录下的 `照片管家.log`；该目录无法写入时，尝试写入系统临时目录。
- 设置通常保存在 `%APPDATA%/照片管家/last.ini`；无法使用该位置时尝试程序目录或临时目录。
- 日志和设置可能包含本机路径。反馈问题或分享截图前，请删去不想公开的信息。
- 仓库的 `.gitignore` 已排除这些文件和编译产物。

## 已知限制与常见问题

- 判重依据文件大小和 SHA-256，不识别“画面相同但重新压缩、裁剪或修改过元数据”的照片。
- 无权访问或无法读取的文件、目录可能被跳过；请检查日志，不能将扫描结束等同于所有文件都已成功处理。
- 试运行不写入源目录和目标目录，但不会模拟真实写入权限、磁盘空间或全部复制故障；它也不是回滚功能。
- 大文件复制期间，停止操作可能需要等当前复制调用返回。
- 回收站行为取决于 Windows、磁盘类型和系统设置。重要照片请另留备份。
- 遇到“访问被拒绝”，先检查目录权限、文件占用及 Windows 安全中心的拦截记录；仅凭这个错误无法确认原因。
- 源文件夹和目标文件夹应使用互不嵌套的独立目录。
